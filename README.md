# pindoudou(拼豆图纸生成器)

极简风格的拼豆图纸生成网站,纯静态,浏览器本地完成,无需服务器。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 主网站(编辑器 + 手动编辑 + 导出页) |

## 功能清单

### 编辑器
- 图片上传(JPG/PNG)+ CSV 图纸导入 + 拖拽
- **4 种处理模式(预设 1-4)**: 卡通效果(默认)/ 写实还原 / 强化合并 / 纯色板映射
- **图纸尺寸预设**: 29×29 / 52×52 / 78×78 / 104×104,可自定义任意宽高(10-500 格)
- **参数预设**: 简约(合并25/上限12) / 标准(合并15/上限30) / 精细(合并5/上限45) / 自定义,默认 合并30/上限30
- 颜色合并值范围 0-30、颜色上限范围 8-45(可关上限)
- 5 品牌色板实时切换 + 可视化色板网格(悬停显色号)
- 统计:尺寸/总豆数/用色数 + 各色号用量图例

### 手动编辑
- 画笔 / 取色 / 魔棒 / 橡皮 / 填充 / 高亮 / 拖拽 / 撤销
- 画笔颜色与大小自定义、一键去背景、去除杂色、色号坐标
- 水平翻转、空白画布(自由设计)

### 导出图纸页
- 三种预览模式:主图 / 镜像图 / 效果图
- 图纸文案:名称 / 作者(可编辑)
- 下载设置:色号开关 / 豆数统计开关 / 网格辅助线开关 / 网格线颜色
- 下载 PNG + 分享保存(Web Share,降级下载)
- 格内色号、四边坐标、每 5 格加粗网格线、底部统计区

### CSV 导出
- 色号网格 CSV(空白格 `.` / `ERASE`),可用拼豆软件打开
