# 拼豆图纸生成器(1:1 复刻版)

基于你确认自有的 xiaoana.cn「草莓拼豆图纸生成器」前端 bundle 还原重建的独立网站。**功能与原站 1:1 对齐,去掉卡密/登录墙,全部在浏览器本地完成。**

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 主网站(编辑器 + 手动编辑 + 导出页) |
| `ai-prompts.html` | AI 图片风格口令页(对比图 + 复制口令) |
| `ai-prompts.json` / `ai-img/` | 口令数据 + 对比图(已本地化,离线可用) |
| `palette.js` | 5 品牌完整色板: MARD / COCO / 漫漫 / 盼盼 / 咪小窝(291 色 × 5) |
| `tuzhitu.png` / `logtu.png` / `logtu.jpg` | 品牌图(图纸Logo/站标) |
| `test-image.png` | 示例测试图 |
| `test-core.js` | 核心算法无头验证脚本(可选) |

## 功能清单(与原站对齐)

### 编辑器
- 图片上传(JPG/PNG)+ CSV 图纸导入 + 拖拽
- **4 种像素化算法**:色板(默认)/ 平均 / 主色(肤色检测+对比度加权)/ 卡通(CIELAB)——按原站 bundle 等价移植
- 图纸尺寸(宽度 10–200 格,高度联动锁定比例)
- 颜色合并值 0–100 + 颜色数量上限(超限自动归并)
- 5 品牌色板实时切换 + 可视化色板网格(悬停显色号)
- 统计:尺寸/总豆数/用色数 + 各色号用量图例

### 手动编辑(复刻原站工具栏)
- **画笔 / 取色 / 魔棒(同色连通选择填充) / 橡皮 / 填充 / 高亮 / 拖拽**
- 画笔颜色自定义
- **水平翻转**
- **空白画布**(自由设计)
- **文字生成**(最多 5 字 → 画布像素化,复刻原站弹窗流程)

### 导出图纸页(复刻原站完整流程)
- 三种预览模式:**主图 / 镜像图(水平翻转) / 效果图**
- 实时预览(设置变化立即重新生成)
- 图纸文案:名称 / 作者(可编辑)
- 下载设置面板:色号开关 / 豆数统计开关 / 网格辅助线开关 / 网格线颜色(9 预设)
- 下载 PNG + 分享保存(Web Share,降级下载)
- PNG 渲染还原原站:格内色号、四边坐标、网格辅助线(每5格加粗)、底部统计区(色号块+数量+总豆数/色数/尺寸)、标题栏+品牌Logo
- 文件名原版格式: `caomeipindou-<名称>-<N>x<M>.png` / `-mirror` / `-effect`

### AI 图片风格口令页
- 6 种风格卡片:原图/效果左右滑动对比
- 一键复制完整 prompt(去背景像素图 / Q版卡通 / 宠物Q版 / 照片转像素 等)
- 数据与对比图取自原站 `/api/ai-prompts` 并已本地化

### CSV 导出
- 色号网格 CSV(空白格 `.` / `ERASE`),可用拼豆软件打开

## 部署

纯静态站,无需服务器:

```bash
# 方式1: 双击 index.html 本地直接使用(全部功能离线可用)
# 方式2: 任意静态托管 (Vercel / Netlify / GitHub Pages / 你的服务器)
# 方式3: 本地起服务
npx serve .
```
